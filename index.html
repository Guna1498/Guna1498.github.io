Career Kompass: AI Career Coach MVP

Built and deployed an MVP for the founder of Career Kompass. Users paste a job description and upload a CV to get a per-skill gap analysis with match scores, a JD-tailored CV rewrite with before/after diff, a cover letter, and a prioritised action plan. FastAPI backend using DeepSeek with automatic fallback to Llama 3.3 70B on Groq, Supabase auth and saved history, and CV export to PDF and DOCX in multiple templates. CV files are processed in memory and never stored (GDPR by design). Deployed on Vercel and Render.

Generative AI for Aerial Image Analysis

Master's thesis. Evaluated open-source VLMs (Qwen-2.5-VL-7B) via zero-shot & few-shot prompting to classify attic usability across 745 annotated aerial building images, achieving up to 81.6% accuracy. Built a multimodal inference pipeline linking imagery to PostgreSQL geospatial records. Benchmarked 6 VLMs and analysed XAI failure modes including hallucination and spatial misalignment.
